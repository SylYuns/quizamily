# Quizamily

Application de quiz familial : les membres d'une famille ajoutent des informations sur les personnes centrales (grands-parents, arrière-grands-parents...), l'app en tire des questions fermées envoyées chaque semaine, et les résultats enrichissent une archive familiale.

Projet en phase de planification (concept + modèle de données). Stack envisagée : Expo (React Native) + Supabase.
